# 도우미 화면 캡처 2차 (UI 팀, PR #32)

UI 팀이 PR #32(`29235e2e53`)에서 에뮬레이터로 찍은 화면이다. 여기콕 통합 빌드의 화면이 아니다.

| 파일 | 내용 |
|---|---|
| `home-on.png` | 도우미가 켜진 홈. 밝은 원과 숨 쉬는 움직임 |
| `home-off.png` | 도우미가 꺼진 홈. 수면모자를 쓴 콕콕이 |
| `practice-open.png` | 연습용 설정 앱에서 도움 버튼을 연 화면 |
| `practice-question.png` | 연습용 설정 앱에서 질문을 입력한 화면 |
| `thinking.png` | 생각 중 화면 |
| `consent.png` | 화면 정보 전송 동의 화면 |
| `launcher-overlay.png` | 런처 위에 뜬 도움 버튼 |

## 여기콕과 다른 점

- 화면 맨 위 이름이 콕콕이이다. 여기콕에서는 앱 이름 여기콕이다.
- ‘도움 버튼 켜기’와 ‘도움 버튼 잠시 끄기’가 보인다. 여기콕에는 ‘도우미 켜기’와 ‘도우미 종료’가 있고, 도움 버튼은 대화 중에만 나타난다.
- ‘개발 테스트’ 링크가 보인다. 여기콕에는 이 링크가 없다.
- 동의 화면에 ‘Google Gemini’와 ‘스크린샷은 보내지 않아요’가 적혀 있다. 여기콕은 실제 받는 곳과 실제로 보내는 정보(음성, 입력한 글, 화면 글자·버튼 이름·위치, 화면 사진)를 적는다.
- 마이크는 받아쓰기용이다. 여기콕에서는 실시간 음성 대화에 쓴다.
